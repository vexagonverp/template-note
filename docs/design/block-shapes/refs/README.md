# Block Shapes: references

Inspiration only. Nothing here goes on a slide. To study a GIF, pull frames into `.temp/`:
`ffmpeg -i <file>.gif -vf "select='not(mod(n\,30))',scale=300:-1,tile=4x2" -frames:v 1 .temp/sheet.png`.

| File | What it shows | Source | What to take from it |
|------|---------------|--------|----------------------|
| `reality-in-motion_poster_animated.gif` (447x632, 240 frames, about 7 s loop) | "Reality in Motion" poster (Tame Impala, Currents): giant condensed black headline top-left, thin light text column top-right with credits, a 3x3 grid of flat tiles below. The shapes move: an eye looks around, a half-circle tips, a red-orange band flips direction, a triangle and a square swap, ellipses stack and unstack. | Pinterest via Klickpin (no pin ID in the file name) | The main reference: same palette, type contrast and tile grid as this style. Ideas not used yet: **tile shapes that move a little when the slide opens**, a **sunburst** shape (pink tile, red-orange rays), stacked ellipses as "levels". It also puts violet shapes on marigold and on black, which we avoid for contrast. |
| `reality-in-motion_poster_frame.png` | First frame of the GIF as a still. | made from the GIF | Quick look without extracting frames. |
| `warm-tile-pattern.jpg` (720x720) | 3x3 geometric tiles in a warm palette (orange, rust, sand yellow, charcoal): triangles, a ring, a diagonal capsule with a dot, a four-point star, checkers, a framed square. | Pinterest via Klickpin, pin 668080926014590199 | A different palette, same idea. Extra shapes to borrow: **ring**, **four-point star**, **checker**, **diagonal capsule**. A possible warm variant of this style. |
