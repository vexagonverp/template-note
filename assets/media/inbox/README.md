# Inbox

Drop images, GIFs or clips here with the background already removed (transparent PNG),
any file name. Then tell Claude "process the inbox". Each file gets checked (transparency,
size), trimmed, kept in its original colors, split if it holds several objects, renamed,
moved to the right folder in `assets/media/` (for example `objects/`), and listed in
`assets/media/README.md` with its source. The inbox is empty again afterwards.
