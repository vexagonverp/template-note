# Prompt: improve an existing sheet

Short follow-ups that worked well. Use any of them on an existing sheet.

- "Format the questions like the actual question paper so I can reference them"
  → blue question boxes with exact wording, equation numbers, and source.
- "Make the steps easy to follow in the exam" → red STEP badges with names, the same
  step names in the guideline and the worked example.
- "Update the answers in the same style" → green answer boxes, parts (a)(b)(c), final
  results boxed, pseudocode as numbered lines.
- "These photos are the teacher's hints" → list them on page 1, cover each one, and
  follow the hint where it differs from the pool.
- "Explain it like I'm stupid, no page limit" → add the "math from zero" part, slow down
  every calculation, add "Row 1 in words" under tables.
- "What does <symbol/line> mean?" → answer, and add the plain explanation in the sheet
  at that spot.
